# Enquête à Assigamé

Jeu d'enquête en point-and-click, autour du chantier du Grand marché de Lomé (Assigamé), un samedi de 2026. Retrouve la malle de wax anciens de Dada Akossiwa avant le car de 14 h pour Cotonou : interroge, examine, et confronte les témoins avec les bons indices.

```bash
npm install
npm run dev   # http://localhost:5176
npm test
```
